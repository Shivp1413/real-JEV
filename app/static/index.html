What is real-JEV?

real-JEV is a local, open clone of the Jev “System One” idea, inspired by GitHub Next’s LocalJev. Instead of free-form chat, you give it context + typed questions and get back constrained answers with probabilities — ideal for routing, classification, scoring, and guardrails.

Question types

Choice

Pick one option from a set. Returns the winner + a probability for each option.

Score

Rate against an ordered rubric (low → high). Returns the chosen level + expected score.

Noul

A single probability in [0, 1] that the answer is “yes”.

Runs 100% locally. Your context never leaves your machine unless you enable web search. Probabilities are self-reported by the model — calibrate before consequential use.
